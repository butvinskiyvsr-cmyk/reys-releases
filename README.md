# Рейс — выпуски Windows

[Скачать последнюю версию](https://github.com/butvinskiyvsr-cmyk/reys-releases/releases/latest)

В этом публичном репозитории размещаются только установщики Windows, `latest.yml` и `.blockmap` для автоматического обновления. Исходники находятся в отдельном закрытом репозитории. Базы, отчёты, аккаунты организации и секреты здесь не публикуются.

Скачайте `Reys-Setup-X.Y.Z.exe` из Assets выбранного выпуска и установите клиент. При первом запуске укажите HTTPS-адрес сервера своей организации. Сервер развёртывается отдельно.

Начиная с 0.2.0 клиент автоматически проверяет выпуски при запуске и каждые 6 часов. Загрузка и установка с перезапуском доступны через меню «Рейс → Обновления приложения…». Перед перезапуском сохраните открытые формы. Для перехода с 0.1.0 нужна первая ручная установка 0.2.0.

Установщик пока без сертификата подписи издателя. Контрольные суммы файлов доступны на странице выпуска. Доступ к приложению определяется аккаунтом на сервере организации; публичность установщика не открывает доступ к рабочим данным.
