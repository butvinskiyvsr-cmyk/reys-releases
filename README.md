# Рейс — выпуски Windows

[Скачать последнюю версию](https://github.com/butvinskiyvsr-cmyk/reys-releases/releases/latest)

В этом публичном репозитории размещаются установщики Windows, `latest.yml` и `.blockmap` для автоматического обновления. Исходники находятся в отдельном закрытом репозитории. Базы, отчёты, аккаунты организации и секреты здесь не публикуются.

Скачайте `Reys-Setup-X.Y.Z.exe` из Assets выбранного выпуска, закройте Рейс и запустите установщик. Начиная с 0.2.1 клиент автоматически подключается к `https://reyslogistics.org`: вводить или выбирать адрес не нужно. При недоступности сервера главное окно показывает состояние подключения и повторяет попытку каждые 15 секунд.

В общем плане и профиле обновлённого веб-интерфейса отображаются состояние синхронизации и время последнего успешного обновления. Сервер организации развёртывается отдельно; сейчас он готовится к запуску, поэтому клиент может показывать «Нет подключения».

Начиная с 0.2.0 клиент автоматически проверяет выпуски при запуске и каждые 6 часов. Загрузка и установка с перезапуском доступны через меню «Рейс → Обновления приложения…». Перед перезапуском сохраните открытые формы. Для перехода с 0.1.0 нужна первая ручная установка текущей версии.

Установщик пока без сертификата подписи издателя. Контрольные суммы файлов доступны на странице выпуска. Доступ к рабочим данным определяется аккаунтом на сервере организации.
