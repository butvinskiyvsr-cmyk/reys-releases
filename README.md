# Рейс — выпуски Windows

[Скачать последнюю версию](https://github.com/butvinskiyvsr-cmyk/reys-releases/releases/latest)

В публичном репозитории размещаются установщики Windows, `latest.yml` и `.blockmap` для обновления. Исходники находятся в отдельном закрытом репозитории. Рабочие базы, отчёты и секреты здесь не публикуются.

Скачайте `Reys-Setup-0.3.0.exe`, закройте старую версию и запустите установщик. Не удаляйте папку данных приложения.

Начиная с 0.3.0 приложение сразу открывает локальное рабочее место, включая первый запуск без сети. Можно создавать и редактировать рейсы, водителей и транспорт. Данные и очередь отправки сохраняются после закрытия программы. Красный индикатор и число ожидающих изменений видны вверху; подробности — в «Моём профиле».

Сервер организации — `https://reyslogistics.org`, вводить адрес не требуется. Для обмена один раз подключите рабочий аккаунт в профиле. После восстановления связи очередь отправляется в фоне; конфликты требуют проверки пользователем. Общий сервер ещё готовится к запуску. До его развёртывания доступна локальная работа, обмен ожидает подключения. Веб-кабинет в обычном браузере требует доступного сервера.

Программа проверяет новые выпуски при запуске и каждые 6 часов. Загрузка и установка с перезапуском доступны через меню «Рейс → Обновления приложения…». Перед перезапуском сохраните открытые формы. Для перехода с 0.1.0 нужна ручная установка текущей версии.

Установщик пока без сертификата подписи издателя. Контрольные суммы доступны на странице выпуска. Локальные данные находятся в профиле Windows; доступ к общей базе определяется рабочим аккаунтом на сервере.
